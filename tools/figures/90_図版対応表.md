# 図版対応表

**Civilizational Enhancement | Draft v0.6 | 最終更新 2026年8月28日**

本文の図版番号、作図コード、出力ファイル、可視化形式、データの性格、出典の対応表。この表の本体部分は `mk_table.py` が `90_map.md` として生成する(改訂記録と削除記録は手で保守している)。表と本文と作図コードの三者は、常にこの順で一致していなければならない。

- 図版は全27点。作図はすべて `figures.py` の一ファイルにあり、関数名は `fig<章><番号>` である。
- 描画の共通スタイルは `bookstyle.py`、ヴォロノイ・ツリーマップやサンバーストなどの幾何プリミティブは `charts.py` にある。外部ライブラリに頼らず実装してあるのは、作図の各段階を監査できるようにするためである。
- **フォント。** ET Book(ETBembo)のTTFが `~/.fonts/` にないと代替フォントになる。入手は `npm pack typeface-et-book` が最も確実で、展開した `package/et-book/source/4-ttf/*.ttf` を置けばよい。
- 再生成は `python3 run_china.py && python3 figures.py`。PNGとSVGを各27点、`figures/` に書き出す。

## 2026年8月28日の全面改訂について

この日、図版を31点から26点へ整理し、残る図の可視化形式を見直した。

**削除した5点。** 主張に対する付加価値がないと判断したものである。

| 旧番号 | 内容 | 削除の理由 |
|---|---|---|
| 旧図1-3 | Ayres-Warrモデルの適合 | 描画データが合成であり、二本の線がほぼ重なって「1975年以降に約12%の残差が再出現する」という肝心の差が読めなかった。本文の記述のほうが正確である。 |
| 旧図1-4 | 産業用電気料金の国際比較 | 四つの数値の棒グラフ。同じ四数値が直前の本文と第3章の本文の двух箇所に書かれており、図が加えるものがない。 |
| 旧図5-2 | 光への支出のGDP比 | 同一の値(0.72%)を三点打つだけの図だった。新しい図5-1の右パネルに統合し、価格の崩落と並べて初めて意味を持つ形にした。 |
| 旧図5-4(番号は新図に再利用) | 電力比率と世界電力需要の見通し | IEAシナリオの投影線であり、本文の二つの数値以上のことを述べていなかった。 |
| 旧図6-2 | AI高露出職種の若年雇用 | **同一推計の三つのヴィンテージ(2025年8月13%、11月16%、2026年6月19%)を時系列として結んでいた。** 実際には推計値の改訂であって観測された悪化の推移ではないため、図として誤りである。本文は留保を明記しているので、本文に委ねる。 |

**番号は詰めた。** 旧図1-5→図1-3、旧図5-3→図5-2、旧図5-5→図5-3、旧図6-3→図6-2、旧図6-4→図6-3。欠番はない。

**可視化形式を変えた11点。** 棒と折れ線に偏っていたため、データの構造が最もよく出る形式へ移した。

| 図 | 旧形式 | 新形式 | 変更の理由 |
|---|---|---|---|
| 図1-1 | 対数折れ線(1万2千年) | ユニットチャート | 線形の時間軸では全期間がホッケースティックになり、右端の一本の垂線しか読めなかった。1目盛=100W=人体一人分としたことで、「米国人一人が88人分のエネルギーを動かしている」という量そのものが図になる。 |
| 図2-2 | 折れ線 | 二面パネル(面+帯) | 需要側だけを描いていた。効率側を並べて初めてジェヴォンズの逆説が図になる。効率は水準が公表されていないため、系列ではなく帯として描いた。 |
| 図3-3 | 棒グラフ | ユニットチャート | 1目盛=1時間とすることで、573時間という量が面積として直接読める。 |
| 図4-1 | 横棒 | スロープチャート(対数) | 分岐そのものが主張であり、二時点を結ぶ線のほうが「同じ経済の中で価格ベクトルが二方向へ割れた」という構造を示せる。 |
| 図4-2 | 7カ国の合成ロジスティック曲線 | リッジラインプロット | **旧図は数式で生成した架空の曲線だった。** World Bankの217カ国×1960〜2024の実データに差し替え、各年の人口加重分布を重ねた。「世界人口の三分の二が置換水準未満」という本文の主張が、67.4%として図の中で直接検算できる。 |
| 図4-6 | 横棒(上位15カ国) | ヴォロノイ・ツリーマップ(二階層) | 順位ではなく面積の分布が主張である。地域ブロックの中に国のセルを入れ子にしたことで、「サブサハラ・アフリカと南アジアで過半」が一目で読める。 |
| 図5-1 | 折れ線(価格のみ) | 二面パネル | 旧図5-2を統合。価格が三千分の一になったことと、支出割合が動かなかったことは、並べて初めて命題になる。 |
| 図5-2 | 4点の対数散布 | 対数階段 | 「越えた桁」と「まだ越えていない桁」を、実線と破線で区別した。 |
| 図6-2 | 棒グラフ(実施国数) | ライフラインチャート | 数を数えるより、どの国がいつ手放したかを見せるほうが情報が多い。アイスランドの一時復活とスペインの中断・再導入も同じ図に入る。 |
| 図7-1 | 3本の横棒 | 比例円 | 面積比が主張であり、棒の長さでは「見えていない部分の大きさ」が伝わらない。 |
| 図7-2 | 積み上げ横棒 | サンバースト(二層) | 内側の環に「GDPに入るか否か」を置くことで、一日の構造とその計上可否を同時に読める。 |
| 図8-1 | 枠線の模式図 | コード図(二部) | 分業と垂直統合の対比が主張である。中国ブロックのリボンが一点から扇状に出る形と、米国ブロックが軸ごとに別の場所へ分かれる形の対比が、そのまま図になる。項は第1章の式を分解したものであり、図と式が同じ語彙で読める。 |

**残した図の形式は変えていない。** 図1-2、1-3、2-1、2-3、3-1、3-2、3-4、4-3、4-4、4-5、5-3、6-1、6-3、8-2。いずれも折れ線・面・年表・散布が当該データにとって最適であり、形式を変える理由がない。多様性は目的ではなく、データの構造に形式を合わせた結果である。
